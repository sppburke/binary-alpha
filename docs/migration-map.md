# Migration map

## Source revision and provenance

The legacy system is the Python and JavaScript research and browser-trading workspace pinned at
[revision b509964](https://github.com/oniram93/rexi3/tree/b509964cd1c40180e9d98b0e55a95699b0abe9ed).
At that revision it holds 363 Python files, four JavaScript modules, 217 Python entry points, 69 files
that mutate the import path, and no Rust manifest. It has no license file; no license metadata is
asserted here. Its product names are not used as target names anywhere in this repository; legacy
paths appear only inside link destinations pinned to that revision.

The current checkout retains the thirteen device kernels in `crates/accelerator/kernels`;
[SOURCES.md](../crates/accelerator/kernels/SOURCES.md) records the extracted digests and the
flattened condition layout. The kernel-contract port is complete. Search orchestration, sampling,
portfolio objective construction and selection, and the flip-selection workflow remain Phases 08/09.
Each later phase cites the pinned revision and the file and lines whose behavior it reproduces.

## Dispositions

- **port**: reimplement the evidenced behavior in Rust under the contracts in `docs/contracts.md`.
- **combine**: merge several legacy implementations of one concern into one target owner.
- **replace**: implement the concern under different contracts; the legacy behavior is not reproduced.
- **delete**: no target counterpart.
